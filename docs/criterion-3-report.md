### Known limitation — load-induced false negatives (non-gating, environmental)
Under pathological host load (observed only at load average ≥~26; absent at ≤12 — these load figures are **session-local, unverified external observations, non-gating**), MIRAI's timeout-bounded analysis can **drop** expected diagnostics — a false *negative*, not a false positive. Two independent, orthogonal timeouts contribute: the 100 ms per-Z3-query wall-clock timeout (`z3_solver.rs:67`) yielding `SmtResult::Undefined`, and the per-function analysis budget (`BodyTimeout`). This is a global CPU-starvation artifact affecting generic fixtures (e.g. `arc_load_thin_pointer`, `model_field_arc_alias`, `callback_carrier`) and is **not** a soundness gap in the socket-decode gate: the Criterion 3 decode cells route through the pre-solver, deterministic `EncodingIncomplete` path (`body_visitor.rs`, `existential_encoding_is_complete`) and are timeout-invariant by construction — they never regressed under load. A per-query high-timeout re-solve on `Undefined` was implemented and load-tested (@opus); it did **not** eliminate the flakiness (15/20 under synthetic load 26–62 — a **session-local, unverified external measurement with no committed artifact, non-gating**) because it cannot address the orthogonal `BodyTimeout` and can worsen it by consuming the body budget, so it was reverted on canonical (`317806b`). Recorded as a documented environmental limitation, not a Criterion 3 regression. The direction is dictated by construction: every `Undefined` arm is non-emitting (`call_visitor.rs:5289` is `=> continue`), so a timeout can only drop a true positive, never add a spurious note. This non-emitting behavior was made explicit by `23d186a` (which separates solver timeout from incomplete encoding while `EncodingIncomplete` still retains the guarded diagnostic; test `complete_boolean_query_distinguishes_incomplete_encoding_from_solver_timeout`, 30/30 stable under load) — so no spurious-note (false-positive) path remains open, and the residual is exclusively the load-induced false negative described here.
